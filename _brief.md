## Key Decisions Made
- **Locked-screen dual-view toggle is a feature** — no fix needed; officially documented as intended behavior.
- **Deploy path is the dashboard sync flow.** When chat-side VPS tooling is unavailable (happened this cycle), "ask team to sync" in the VPS dashboard is the authoritative route — and the CEO won't fake a deploy; public-URL byte verification is required before declaring done.
- **Single-element audio architecture** — one persistent `primaryVoiceAudio`, gesture-unlocked on Start; eliminates all fallback/shared audio element paths.
- **iOS long-session path = push notifications** — silent-loop sustain is unreliable on iPhone by platform design; push carries phase-end/voice for long focus sessions ("the frog finds you").
- **Deploy discipline: touch only `index.html`.** Commits are rewritten single-file to avoid platform auto-commit sweeping `_hub.html`/`_portal.html`.
- **`master` is the production branch**; `main` is legacy.
- Unchanged from prior brief: TTS route contract, `.env` key handling, locked publish scope, `frogfocus.live` parked.
